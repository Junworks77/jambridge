# JamBridge

참고 이미지의 프렛보드, 스트로크 패턴, 코드 진행을 바탕으로 만든 한국어 일렉기타 연습 웹 앱입니다. React, TypeScript, Vite와 Web Audio API를 사용합니다.

## 실행

Node.js 22 이상에서 실행하세요.

```sh
npm install
npm run dev
```

브라우저에서 터미널에 표시된 주소를 여세요. 기본 주소는 `http://localhost:5173`입니다.

```sh
npm run build    # 타입 검사 및 프로덕션 빌드
npm run preview  # 빌드 결과 확인
```

## 연습 기능

- **타브 생성:** 로컬 서버에서 MP3 stem 분리, 곡 구간·BPM·Key·박자 추정, 기타 채보·운지 추천, 편집·튜닝·카포, 동기 믹서와 자동 스크롤을 제공합니다. 서버 설치는 아래를 확인하세요.

- **프렛보드:** 표준 튜닝, 12–22프렛, 6가지 스케일, 코드톤, CAGED 메이저 폼, 음이름/도수 및 샤프/플랫 표기, 근음 강조, 클릭 음 재생.
- **리듬훈련:** 2/4·3/4·4/4·5/4·5/8·6/8·7/8·9/8·12/8의 9가지 박자, 강세 묶음 선택, 장르별 프리셋 17개, 16분음표 단위 편집, 재생 위치 표시, 클릭/드럼/스윙, 버튼으로 박자 타이밍 연습. 긴 패턴은 모바일에서 가로로 탐색하며 재생 위치를 따라갑니다.
- **잼플레이:** 추천·재즈·블루스·순환 27개 프리셋, 최대 128개 코드 이벤트, 코드별 0.5–16박 길이, 고급 화음과 슬래시 베이스, 구성음 직접 편집, 진행 이어 붙이기·복제·순서 이동·실행 취소, 사용자 진행 저장 및 JSON 가져오기·내보내기. 키 변경 시 베이스도 함께 조옮김합니다.
- **메트로놈:** 30–240 BPM, 리듬훈련과 같은 9가지 박자 및 강세 묶음 공유, 4분·8분·16분음표 분할, 첫 박자·묶음 시작 강조, 스윙, 탭 템포. 8분음표 박자에서는 8분·16분음표 클릭을 선택합니다.
- **연결된 연습:** 키·스케일·BPM 공유, 잼 반주를 유지하면서 프렛보드 보기 및 현재 코드 표시, 세션 저장/불러오기, 오늘의 연습 시간, 모바일 화면.

하단 재생 버튼 또는 Space로 소리를 시작합니다. 1–5는 도구 이동(5: 타브 생성), T는 탭 템포, 위/아래 화살표는 BPM 조절입니다. 입력창이나 버튼에 포커스가 있으면 해당 요소의 기본 키 동작을 우선합니다.

## 타브 생성 서버 설치

Python **3.11**, FFmpeg(`ffmpeg`와 `ffprobe`가 PATH에 있어야 함), 여유 디스크 공간이 필요합니다. Windows PowerShell에서 프로젝트 루트 기준:

```powershell
py -3.11 -m venv server/.venv
server/.venv/Scripts/python.exe -m pip install -r server/requirements.txt
npm run server
```

macOS/Linux에서는 `python3.11 -m venv server/.venv`와 `server/.venv/bin/python -m pip install -r server/requirements.txt`를 사용합니다. `npm run server`는 프로젝트 가상 환경을 자동 선택합니다. `JAMBRIDGE_PYTHON`으로 실행 파일을 지정할 수도 있습니다. 이 작업 환경에 준비된 포터블 Python(`.tools/python/python.exe`)도 자동 탐지합니다.

다른 터미널에서 `npm run dev`를 실행합니다. 기존 개발 서버가 실행 중이었다면 재시작하세요. Vite가 `/api`를 `127.0.0.1:8000`에 연결합니다. `npm run preview`도 같은 로컬 서버를 사용하며, 정적 파일만 호스팅하면 분석은 동작하지 않습니다. 인터넷 공개 서버 배포는 지원하지 않습니다.

한 호스트에서 타브 생성까지 함께 서비스하려면 `npm run build` 후 `npm start` 하나로 정적 앱(Vite preview, 포트 4173)과 분석 서버(127.0.0.1:8000)를 같이 띄웁니다. `Ctrl+C`(또는 `SIGTERM`)로 둘 다 함께 종료하며, 한쪽이 죽으면 다른 쪽도 내립니다. 분석 서버는 여전히 로컬 전용이므로 systemd·pm2 같은 프로세스 매니저로 이 한 명령을 감싸 단일 단위로 시작·중지하세요.

분석 서버는 `Origin` 호스트네임이 `localhost`/`127.0.0.1`/`::1`이 아니면 403을 돌려줍니다. `localhost`가 아닌 주소(예: `http://192.168.0.10:4173`)로 접속하려면 환경변수 `JAMBRIDGE_ALLOWED_HOSTS`에 그 호스트를 콤마로 나열합니다(`*`는 검사 해제, 신뢰망 전용).

### 사용 흐름

0. **타브 생성** 화면은 로컬 서버 로그인 후에 열립니다. 처음이면 아이디·비밀번호로 계정을 만들고, 이후에는 로그인합니다. 계정은 이 PC의 `server/data/account.json`(비밀번호는 PBKDF2 해시)에 한 개만 저장되며, 로그인 토큰은 브라우저의 `jambrigde-tab-auth`에 보관됩니다. 로그인 세션은 서버 메모리에 있어 서버를 재시작하면 다시 로그인해야 합니다. 비밀번호를 잊으면 `account.json`을 지우고 다시 만듭니다.
1. **타브 생성 → MP3 업로드**에서 100MB·10분 이하 파일을 고릅니다. 업로드 후 원곡을 바로 들을 수 있습니다.
2. **stem 분리 · 타브 생성**을 실행합니다. 첫 실행에 Demucs 모델을 다운로드해 캐시합니다. CPU도 지원하지만 곡 길이·PC에 따라 수 분 이상 걸릴 수 있습니다. CUDA용 PyTorch가 설치되어 있으면 분리에 GPU를 사용합니다. 기본 설치와 채보 ONNX 실행은 CPU를 지원합니다.
3. BPM·Key·박자·첫 마디·구간을 확인하고 수정합니다. 박자는 `3/4, 4/4, 5/8, 7/8, 12/8`의 강세 주기 비교 결과입니다. `구간 A/B`는 반복 유사도 이름으로 후렴/벌스 확정 판정이 아닙니다. BPM은 4분음표 기준입니다. 기본은 실제 박 위치를 사용하고 BPM/첫 마디를 직접 수정하면 고정 템포 격자로 바뀝니다. 수정은 원곡 속도·피치를 바꾸지 않습니다.
4. **stem 믹스**에서 Vocal·Drums·Bass·Guitar·Piano/Other의 볼륨·음소거·솔로를 조절합니다. 여러 솔로는 함께 재생하고 음소거가 우선입니다. 모든 채널은 같은 시계로 재생하고 다음 오디오가 준비되지 않으면 함께 버퍼링합니다.
5. 표준/Drop D/반음 다운 또는 현별 튜닝, 카포, 프렛 범위를 선택합니다. 운지 추천은 프렛·줄·손 위치 이동과 동시음 줄 충돌을 고려합니다. 타브 숫자는 카포 기준이고 지판은 실제 프렛입니다. 불가능한 음은 `미배치`로 남깁니다.
6. 음을 눌러 시간·음높이·대체 운지·주법을 수정합니다. 벤딩(초킹)·슬라이드·해머온·풀오프·비브라토는 추정/편집 표기이며 실제 주법을 보장하지 않습니다. 자동 추정은 점선, 확인 필요는 `!`로 표시합니다. 실행 취소·다시 실행을 지원합니다.
7. 하단 재생바/Space와 구간 반복으로 연습합니다. 직접 스크롤하면 자동 추적을 멈추며 `현재 위치 따라가기`로 복귀합니다. **지판에서 보기**로 이동해도 곡이 이어지고 현재 운지를 표시합니다. 리듬·잼·메트로놈을 실행하면 곡을 일시정지하고 기존 연습 모드로 전환합니다.
8. **저장**으로 분석 수정·타브·믹서·위치를 보관합니다. 탭을 닫거나 다른 곡을 열기 전에 저장하세요. 믹서·마지막 곡 위치는 브라우저에서도 복원합니다. 타브 수정은 녹음된 stem 소리를 바꾸지 않습니다.

파일과 결과는 `server/data/<프로젝트 ID>/`에 저장합니다. 원곡·5개 WAV·오디오 구간 캐시 때문에 MP3보다 많은 공간이 필요합니다. `JAMBRIDGE_DATA`로 저장 위치를 지정할 수 있습니다(계정 파일 `account.json`도 이 위치에 있습니다). 브라우저는 `jambrigde-tab-current`·`jambrigde-tab-auth`와 세션의 프로젝트 참조만 저장합니다. **프로젝트 삭제**는 원곡·stem·편집 타브를 삭제하며 복구할 수 없습니다. 모델 캐시 `.models/`는 별개입니다. 취소·실패 후 재시도하면 완료된 단계를 재사용하며 상세 원인은 프로젝트의 `analysis.log`에 남습니다.

Demucs 6-stem은 실험 모델이며, 여러 기타가 겹치거나 분리 누출이 많은 곡은 채보 수정이 필요합니다. 속도 변경, 베이스 타브, Guitar Pro/PDF 내보내기, 곡과 합성 반주의 동시 재생은 이번 버전에 포함하지 않습니다. 모델 출처는 [server/MODELS.md](server/MODELS.md)에 있습니다.

### 개발 검증

```sh
npm run check:tab
npm run build
```

Python 환경에 `server/requirements-dev.txt`를 설치하고 `python server/check_pipeline.py`로 API·취소·저장을, `python server/check_pipeline.py --models`로 직접 생성한 8초 음원의 실제 모델 처리를 확인합니다. 검증 데이터는 `.tools/check-data`에 격리하고 생성한 프로젝트만 삭제합니다. Playwright를 사용하지 않습니다.

잼플레이 반주의 **음색**은 "신스"(기본 합성음)와 실제 녹음 샘플을 쓰는 "스튜디오"(우드 베이스·나일론 기타), "라이브"(핑거 베이스·재즈 일렉 기타), "스트리트"(우드 베이스·스틸 어쿠스틱 기타), "룸"(픽 베이스·뮤트 일렉 기타), "피아노"(우드 베이스·그랜드 피아노) 중에서 고릅니다. 샘플은 `public/instruments/`에 포함되어 있고(FluidR3_GM 발췌, MIT), 엔진을 처음 선택하면 해당 샘플(약 0.2–0.3 MB)을 불러오는 동안 합성 플럭음으로 재생합니다. 드럼·클릭은 항상 합성음입니다.

**반주 스타일**은 록·팝·발라드·펑크에 더해 보사노바·레게·셔플·스윙·왈츠·컨트리·행진곡·아르페지오를 제공합니다. 각 스타일은 베이스와 코드를 16분음표 격자에 배치하는 규칙(`src/audio.ts`의 `JAM_STYLES`)이며, 리듬훈련 장르 프리셋을 적용하면 함께 설정됩니다.

설정과 세션은 현재 브라우저의 `localStorage`에 저장됩니다. 다른 기기와의 동기화, 마이크 입력 분석, 실제 악기 녹음, 오디오 파일 내보내기는 포함하지 않습니다. 타이밍 피드백은 화면 이벤트 기준이라 오디오 장치 지연을 보정하지 않습니다. Google Fonts에 연결할 수 없으면 시스템 글꼴을 사용합니다.

## 코드 구조

- `src/App.tsx`: 도구 화면, 공통 연습 상태, 브라우저 저장, 접근성 및 키보드 동작
- `src/audio.ts`: Web Audio 스케줄러, 합성 악기·Karplus–Strong 플럭·샘플 재생 엔진, 반주 스타일 표(`JAM_STYLES`), 마스터 볼륨·리미터
- `public/instruments/`: 스튜디오·라이브·스트리트·룸 음색 샘플(출처는 `CREDITS.md`)
- `src/music.ts`: 스케일·코드·CAGED·리듬 데이터와 음높이 계산
- `src/progressions.ts`: 분류별 진행 프리셋. 반음 단위의 상대 근음과 코드 종류·도수·박 길이 데이터만 추가하면 라이브러리에 표시됩니다.
- `src/harmony.ts`: 진행 데이터 검증, 코드 기호 파싱, 슬래시 베이스 조옮김, 오디오와 화면이 공유하는 타임라인
- `src/JamHarmony.tsx`, `src/harmony.css`: 코드 진행 라이브러리, 편집기, 사용자 진행 저장 및 전송
- `src/rhythm.ts`: 박자표·강세 묶음·장르 프리셋 데이터, 클릭·드럼 패턴 및 기존 리듬 설정 마이그레이션
- `src/RhythmPresets.tsx`, `src/rhythm.css`: 장르별 리듬 선택과 박자별 화면 스타일
- `src/styles.css`: 데스크톱·모바일 스타일

프로젝트 루트의 원본 PNG 참고 이미지는 모두 보존했습니다.

## 다양한 박자와 장르별 리듬

리듬훈련 상단에서 장르를 고르고 프리셋을 적용하면 박자표, 강세 묶음, BPM, 스트로크, 스윙, 드럼 패턴 및 반주 스타일이 함께 설정됩니다. 팝·록, 펑크·R&B, 재즈·블루스, 포크·왈츠, 프로그·월드의 연습용 패턴을 제공합니다. 적용한 뒤에도 각 칸을 편집할 수 있으며 ‘패턴 초기화’는 해당 프리셋의 스트로크만 복원합니다.

- 5/8: `3+2` 또는 `2+3`
- 7/8: `2+2+3`, `3+2+2`, `2+3+2`
- 6/8·9/8·12/8: 각각 `3+3`, `3+3+3`, `3+3+3+3`

**모든 BPM과 코드의 명시적 박 길이는 ♩(4분음표) 기준입니다.** 따라서 ♩=120일 때 8분음표 클릭은 0.25초 간격이며, 한 마디는 5/8에서 1.25초, 7/8에서 1.75초, 12/8에서 3초입니다. 12/8의 큰 묶음(점4분음표) 템포는 표시 BPM의 2/3입니다. 탭 템포도 4분음표 기준이고, 리듬 화면의 TAP 연습은 숫자로 표시된 분모 음표 박에 맞춥니다.

패턴은 16분음표 단위로 저장하므로 3/4는 12칸, 5/8은 10칸, 7/8은 14칸, 12/8은 24칸입니다. 수동으로 박자표를 바꾸면 기존 칸의 앞부분을 유지하고 새로 생긴 칸은 쉼표로 채웁니다. 박자표·묶음·프리셋 변경 시 재생은 새 마디의 첫 박부터 시작합니다. 스윙은 두 16분음표의 길이를 바꾸며 전체 마디 길이는 유지합니다. 12/8의 3분할은 박자표 자체로 구현되므로 프리셋에 추가 스윙을 강제하지 않습니다.

박자표, 강세 묶음, 선택 프리셋, 편집 패턴과 오디오 옵션은 자동 저장 및 세션 저장에 포함됩니다. 기존 분자만 저장된 세션은 3→3/4, 4→4/4, 5→5/4로 복원합니다. 코드 진행 JSON의 선택 필드 `timeSignature`는 3/4와 6/8처럼 마디의 4분음표 길이가 같은 박자를 구별하며, 기존 `meter`는 4분음표 길이로 호환성을 유지합니다.

## 커스텀 진행 사용과 확장

‘고급 코드 만들기’에서 근음, 코드 종류, 베이스, 박 길이를 선택합니다. `m7b5`, `dim7`, `maj9`, `m11`, `13`, `7b9`, `7#9`, `9#11` 등을 지원하고, ‘직접 구성음 선택’에서는 근음으로부터의 반음 간격을 2–12개 고를 수 있습니다. 음표 기호로 입력하려면 다음처럼 작성합니다.

```text
Dm9:2 G7(b9):2 | Cmaj7/E:4
```

`|`는 마디 구분이고 `:2`는 2박입니다. 마디 구분 없이 나열하면 각 코드는 기본 한 마디이고, `|`로 나눈 마디 안에서 길이를 생략한 코드들은 마디 길이를 코드 개수로 균등 분할합니다. 명시한 박 길이가 우선하며 마디선을 넘는 길이도 허용합니다. 모든 길이는 0.5박 단위입니다.

프리셋을 적용하면 현재 키는 유지하고 해당 진행의 권장 스케일과 4/4박자를 적용합니다. 이어 붙이기는 기존 설정을 유지하며 각 코드의 명시된 박 길이를 보존합니다. 추천 스케일은 연습의 출발점이며 세컨더리 도미넌트·차용화음·변화화음의 모든 코드톤을 포함하지는 않습니다. 코드 구성음은 고급 편집기의 미리 듣기에서 확인할 수 있습니다.

‘진행 저장’은 브라우저의 `jambrigde-progressions`에 보관합니다. 전체 세션 저장과 별개이며, 불러올 때 현재 키로 조옮김합니다. JSON은 다음 버전 1 형식입니다. 가져오기는 검증 후 내 진행에 추가하며 현재 진행을 덮어쓰지 않습니다.

```json
{
  "version": 1,
  "progression": {
    "id": "my-progression",
    "name": "나의 텐션 연습",
    "root": 0,
    "scale": "major",
    "meter": 4,
    "chords": [
      { "root": 2, "type": "m9", "degree": "ii9", "beats": 2 },
      { "root": 7, "type": "7b9", "degree": "V7b9", "beats": 2 },
      {
        "root": 0,
        "type": "custom",
        "degree": "I*",
        "label": "(my11)",
        "intervals": [0, 4, 7, 11, 14, 18],
        "bass": 4,
        "beats": 4
      }
    ]
  }
}
```

`root`와 `bass`는 C=0부터 B=11까지, `intervals`는 0–24 사이의 정수 반음 간격입니다. 기존 세션의 `beats` 없는 코드는 현재 박자표의 한 마디로 처리합니다. 사용자 진행 데이터와 기본 코드 종류는 검증되며 알 수 없는 코드를 메이저로 바꿔 재생하지 않습니다.

블루스 프리셋은 참고 이미지의 분류를 따르며, 재즈·버드 블루스의 반음계 진행은 [Dirk Laukens의 Jazz Blues Chord Progressions](https://www.jazzguitar.be/blog/jazz-blues-chord-progressions/)의 교육용 예시와 대조했습니다. 프리셋은 연습용 변형을 포함합니다.
